# Simulation figures

Candidate images for the homepage hero (and elsewhere on the site).
Drop files here (PNG/JPG/WebP; ideally at least 1600 px wide). Astro resizes
and optimizes them at build time, so originals can be large.

To use one on the homepage, change the `hero` import at the top of
`src/pages/index.astro` and update its `alt` text and caption.

| File | What it shows | Source |
|---|---|---|
| `weibel-osiris-gpu.png` | 3D Weibel filamentation, 4096-GPU OSIRIS run | Lee et al., J. Plasma Phys. 91, E8 (2025), Fig. 3a |
