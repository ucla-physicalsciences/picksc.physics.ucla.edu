## ZPIC

Our collaborators at IST have been developing a new PIC code for educational use: ZPIC, a 1D/2D
self-contained fully relativistic electromagnetic code running with spectral and finite different solvers.
The efforts with ZPIC are geared towards creating an open source computational toolkit for plasma physics
education inside a virtual laboratory that can be run off-line. The ZPIC educational suite has minimal
set of installation requirements (C compiler for ZPIC, and python3 and jupyter to run the notebooks).
Because of its simplicity, we also encourage you to go through ZPIC source code and make your own changes.

The GitHub repository for ZPIC can be found here: [zpic](https://github.com/zambzamb/zpic).
