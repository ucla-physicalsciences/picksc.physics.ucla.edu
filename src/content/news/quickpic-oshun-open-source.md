The PICKSC group has released QuickPIC and OSHUN as open-source codes.

The public repositories are available on GitHub and may be found here:
[QuickPIC](https://github.com/UCLA-Plasma-Simulation-Group/QuickPIC-OpenSource) and
[OSHUN](https://github.com/UCLA-Plasma-Simulation-Group/OSHUN).

[QuickPIC](/software/quickpic) is a 3D parallel (MPI & OpenMP Hybrid) Quasi-Static PIC code,
which is developed based on the framework UPIC.

[OSHUN](/software/oshun) is a parallel Vlasov-Fokker-Planck plasma simulation code that employs an arbitrary-order spherical harmonic
velocity-space decomposition. The public repository currently houses a 1D C++ version and a 1D pure Python version
(with optional C-modules for improved performance). A 2D C++ version will be added shortly.
