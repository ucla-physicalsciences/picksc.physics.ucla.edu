The PICKSC group has released UPIC 2.0.2, an update to the first release of UPIC (2.0.1). The major new
features here are namelist inputs, a full set of field diagnostics, and initialization with non-uniform
densities. As before, codes can be compiled to run with 2 levels of parallelism (MPI/OpenMP) or OpenMP only.

The primary purpose of this framework is to provide trusted components for building and customizing
parallel Particle-in-Cell codes for plasma simulation. The framework provides libraries as well as reference
applications illustrating their use. The public repository is available on GitHub and may be found
here: [UPIC-2.0](https://github.com/UCLA-Plasma-Simulation-Group/UPIC-2.0)

The files for the 2D and 3D components of UPIC 2.0.2 may also be directly downloaded
[here](/software/upic-framework) on the PICKSC site.
