Alessandro Fanfarillo and Damian Rouson from Italy have translated the PICKSC skeleton code ppic2 to
utilize Coarray Fortran. Coarray Fortran enables a programmer to write parallel programs using a Partitioned
Global Address Space (PGAS) scheme. It is part of the Fortran2008 standard and provides an alternative to the
dominant Message-Passing Interface (MPI) paradigm.

The code [ppic2\_caf](/software/coarray-fortran) is
available here on the PICKSC site.
